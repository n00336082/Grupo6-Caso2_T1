# Evaluación T1 - Caso 2: Billetera Digital

Curso: Soluciones Web y Aplicaciones Distribuidas
Docente: MSc. Víctor Muguerza
Grupo: 06

## Descripción

Este proyecto corresponde al desarrollo del Caso 2 de la Evaluación T1. Consiste en una aplicación web desarrollada en Angular que simula una billetera digital básica, permitiendo registrar recargas y gastos, consultar el saldo disponible y visualizar el historial de movimientos recientes.

## Versiones utilizadas

- Angular CLI: 22.2.4
- Bootstrap: 5.3.8

## Pasos para ejecutar el proyecto

1. Abrir una terminal en la carpeta del proyecto:
   cd caso2-billetera-angular

2. Instalar las dependencias necesarias:
   npm install

3. Iniciar el servidor local de desarrollo:
   npm start

4. Abrir la aplicación en el navegador web:
   http://localhost:4200
